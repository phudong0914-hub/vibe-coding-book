BƯỚC 1 1. Chuẩn Bị Ngữ Cảnh & Nắm Bắt Yêu Cầu (Context Ingestion)

Mục tiêu: Biến mọi ý tưởng, trang web tham khảo hoặc tài liệu PDF thành định dạng Markdown "sạch" để AI nuốt trọn ngữ cảnh mà không bị ngáo hay tràn cửa sổ ngữ cảnh.

🔹 Trường hợp A: Bạn có trang web mẫu / tài liệu trên mạng muốn học theo

Công cụ sử dụng: Firecrawl (Top 1 LLM Crawler)

npx firecrawl crawl https://trang-web-mau.com --output context.md

➡️ Bạn sẽ thu được file context.md chứa toàn bộ cấu trúc & nội dung trang web mẫu dưới dạng Markdown sạch mã thừa.

🔹 Trường hợp B: Bạn có file spec/yêu cầu dạng PDF hoặc hình ảnh

Công cụ sử dụng: OpenDataLoader PDF (Top 1 PDF Parser)

pip install opendataloader-pdf
opendataloader-pdf convert document.pdf --output spec.md

➡️ Gom 2 file context.md và spec.md để sẵn trong thư mục dự án.

BƯỚC 2 2. Thiết Lập Kỷ Luật & Quy Trình Cho AI (Agent Governance)

Mục tiêu: Khóa AI vào khung kỹ thuật chuẩn Senior Engineer của Google, bắt AI phải lập kế hoạch (Plan) và chờ duyệt trước khi gõ bất kỳ dòng code nào.

Công cụ sử dụng: agent-skills (Addy Osmani - Google Chrome Lead) & superpowers (obra - 204K⭐)

💬 Câu Prompt Mẫu Ép AI Lập Kế Hoạch (Copy & Paste vào AI):

"Bạn là Senior Lead Engineer. Hãy tuân thủ bộ quy trình 6 bước trong agent-skills (Define Spec → Plan → Build → Verify → Review → Ship). Dựa vào ngữ cảnh file spec.md ở trên, hãy viết cho tôi file IMPLEMENTATION_PLAN.md chi tiết các module cần làm. KHÔNG ĐƯỢC VIẾT CODE NGAY cho đến khi tôi duyệt PLAN!"

➡️ Đọc qua IMPLEMENTATION_PLAN.md AI tạo ra, sửa đổi nếu cần rồi mới gõ: "Kế hoạch đã duyệt, hãy chuyển sang bước Build!"

BƯỚC 3 3. Thiết Kế Giao Diện & Trải Nghiệm UI/UX (Design Director)

Mục tiêu: Đảm bảo giao diện cực kỳ hiện đại, thẩm mỹ cao (Vibrant Colors, Dark Mode, Glassmorphism, Responsive) thay vì màu xám đơn điệu mặc định của AI.

Công cụ sử dụng: ui-ux-pro-max-skill (92K⭐ Top 1 UI Design Intelligence)

💬 Câu Prompt Mẫu Kích Hoạt Design Intelligence:

"Áp dụng nguyên lý của ui-ux-pro-max-skill, hãy thiết kế cho tôi bộ Design Tokens gồm: Bảng màu HSL chủ đạo (Neon/Dark Mode), Font chữ Google Fonts (Inter/Outfit), độ cong bo góc border-radius, hiệu ứng bóng đổ shadow & hiệu ứng chuyển động micro-animation. Tạo file index.css hoặc styles.css trước!"
BƯỚC 4 4. Vibe Coding, Chạy Test & Tái Cấu Trúc Code (Build, Test & Refactor)

Mục tiêu: Viết code tính năng mượt mà, kiểm thử tự động và tự dọn dẹp code khi dự án phình to.

🔹 Thao tác A: Khi sinh code tính năng

Công cụ sử dụng: claude-code-harness & karpathy/nanoGPT (AutoResearch)

"Hãy viết mã nguồn tính năng [Tên tính năng] dựa trên Design System ở Bước 3. Viết kèm Unit Test và chạy kiểm thử tự động qua Harness môi trường để đảm bảo không có lỗi runtime."

🔹 Thao tác B: Khi dự án vượt quá 500 dòng code hoặc bắt đầu rối rắm

Công cụ sử dụng: refactoringhq/tolaria (Top 1 Refactoring AI)

"Dự án bắt đầu lớn. Áp dụng kỹ thuật Tolaria Refactoring, hãy bóc tách file này thành các module độc lập, loại bỏ code trùng lặp và tối ưu lại cấu trúc thư mục."
BƯỚC 5 5. Rà Soát Bảo Mật & Ship Sản Phẩm (Security Audit & Ship)

Mục tiêu: Đảm bảo ứng dụng web hoặc tool của bạn an toàn 100% trước các đợt tấn công mạng trước khi triển khai công khai.

Công cụ sử dụng: PentesterFlow Agent, Z4nzu/hackingtool & cr0hn/dockerscan

# 1. Quét lỗ hổng Web App (IDOR, SSRF, XSS)
npx pentesterflow scan http://localhost:8000

# 2. Nếu có Docker: Quét lỗ hổng Container
dockerscan image verify my-app:latest

➡️ Đưa báo cáo lỗi bảo mật cho AI fix ngay lập tức. Sau đó chạy git commit và SHIP lên Vercel / Netlify / Server!
